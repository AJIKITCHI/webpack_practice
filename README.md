# カロリーコーチ

食事制限メイン・運動は最小限で「ぽっこりお腹」を落とすための、カロリー管理アプリ。
webpack + Vanilla JS のみで動く SPA で、記録はすべてブラウザ内（localStorage）に保存され、外部には一切送信しない。

## できること

| 機能 | 中身 |
| --- | --- |
| 目標カロリーの自動算出 | 身長・体重・年齢・活動量から基礎代謝と消費カロリーを推定し、減量ペースに応じた目標値を出す |
| PFC バランス | たんぱく質は体重 × 1.6g を確保し、残りを脂質・炭水化物に配分する |
| 食事記録 | 約120品の食品データベース（和食・コンビニ・外食・お酒・お菓子）から選ぶだけ。自分の食品も登録できる |
| AI コーチ | その日の記録を診断し、優先度つきで「いま何をすべきか」を返す |
| 体重グラフ | 実測の減量ペースを最小二乗法で出し、推定式とのズレを目標カロリーに反映する |
| 週次サマリー | 平均摂取・目標内の日数・想定ペースを表示 |

## 使い方

```bash
npm install
npm start        # 開発サーバー http://localhost:8080
npm run build    # dist/ に本番ビルド
npm test         # 計算ロジックとコーチのルールのテスト
```

初回は「設定」タブで体格を入力する。以降は「記録」タブで食べたものをタップしていくだけ。

## 計算の中身

すべて `src/modules/calc.js` にあり、テストで固定してある。

1. **基礎代謝 (BMR)** — Mifflin-St Jeor 式
   `10 × 体重kg + 6.25 × 身長cm − 5 × 年齢 + (男性 +5 / 女性 −161)`
2. **消費カロリー (TDEE)** — BMR × 活動係数（座り仕事 1.2 / 軽い活動 1.375 / 中 1.55 / 高 1.725）
3. **目標カロリー** — TDEE − 赤字（ゆっくり 250 / 標準 500 / 速め 750 kcal）
   ただし男性 1500kcal・女性 1200kcal、かつ基礎代謝 × 0.9 を下回らないところで止める
4. **PFC** — たんぱく質 = 体重 × 1.6g、脂質 = 総カロリーの 25%（最低でも体重 × 0.6g）、残りが炭水化物
5. **見込み** — 体脂肪 1kg = 7200kcal として、目標体重までの週数を出す

推定式は「平均的な人」の値なので必ずズレる。体重を 5 日ぶん以上記録すると、
実測の傾きから目標カロリーの補正値を提案する（アダプティブ TDEE）。**最終的にはこちらが正**。

## AI コーチについて

`src/modules/coach.js` のルールベース推論エンジン。外部 API を呼ばず、判定はすべてローカルで完結する。
「なぜそう言われたか」がコードを読めば分かり、納得できない助言はルールごと書き換えられる。

診ているのは以下の10点で、重い順（alert → warn → info → good）に並べて返す。

- カロリーの着地見込み（時間帯ごとの自然な消費ペースと比較）
- たんぱく質の充足（運動が少ないほど、不足すると落ちるのが脂肪でなく筋肉になる）
- 脂質の過多と、その発生源（揚げ物・マヨネーズなど具体的な品目名）
- お菓子・甘いものが総カロリーに占める割合
- 飲み物由来のカロリー（満腹感が残らない＝いちばん削りやすい枠）
- アルコール（処理中は脂肪分解が止まるため、内臓脂肪とは相性が悪い）
- 野菜・海藻・きのこの有無
- 塩分の多い構成（水分を抱えて見た目のお腹が張る）
- 21時以降の食事量
- 朝食を抜いた日の反動

さらに、残りカロリーと残り PFC に収まる食品を「たんぱく質効率」で並べ替えて提案する。

## ぽっこりお腹に対する方針

お腹だけを狙って痩せる方法は存在しない。体脂肪が全体として落ちるとき、内臓脂肪は皮下脂肪より先に減る
——つまり **ぽっこりお腹は、全身の減量に対して比較的早く反応する部位** なので、やることは合計カロリーの管理でよい。
運動を増やさない前提では、次の優先順位が現実的。

1. **飲み物・お酒・お菓子から削る** — 満腹感が残らないカロリーなので、削っても空腹が増えない
2. **たんぱく質を先に確保する** — 筋肉が落ちると代謝が下がり、同じ食事量で太るようになる
3. **脂質を減らす** — 1g = 9kcal。「揚げる・炒める」を「焼く・蒸す・茹でる」に変えるだけで数百kcal動く
4. **主食は最後に調整する** — 極端に抜くと続かない。茶碗1杯を半分にする程度で十分
5. **塩分と睡眠** — 塩分過多はむくみで、寝不足は翌日の食欲増加で、どちらも見た目のお腹に効く

減量ペースは体重の 0.5〜1%／週 まで。それより速いと筋肉が削れ、リバウンドしやすくなる。

## 構成

```
src/
  index.js            画面の組み立てとイベント処理
  index.html          テンプレート
  styles.css          ダーク／ライト両対応のスタイル
  modules/
    calc.js           BMR・TDEE・目標カロリー・PFC（テスト対象）
    foods.js          食品データベースと検索
    coach.js          AI コーチのルールエンジン（テスト対象）
    chart.js          体重グラフの SVG 生成
    storage.js        localStorage への永続化
test/
  calc.test.js
  coach.test.js
```

## 注意

数値は一般的な推定式にもとづく目安であり、医学的な助言ではない。
持病・服薬がある場合、BMI 18.5 を下回る減量を考えている場合は医師に相談すること。
